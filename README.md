# Prompt工程的原则和策略

1.】编写清晰明确的指示 (具体且无歧义)：

- 使用分隔符 (清晰的表示输入的不同部分);

  ```c
  ''' , """ , <> , <tag> , </tag> ;
  ```

- 要求结构化输出 (告诉模型你要的答案格式)；

- 要求检查结果；

- 给模型一些成功的案例 (提供之前成功的案例作为参考).

2.】给模型时间去"思考":

- 给一个回答拆分成多个子步骤；
- 循序渐进 (逐步增加任务的复杂性).

# 模型的局限性

1.】可能会产生虚构的事实 (一般在开放性问题，缺乏一些严格约束的提示)

​	如何避免或减少该可能性：

1. 强调真实性 (基于事实)；
2. 引用来源；
3. 要求自我验证；
4. 建立反馈机制；
